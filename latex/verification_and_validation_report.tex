\section{Introduction}

This report documents the verification and validation activities carried out
for the QUBO-based sensor node placement system. It follows the practices of
IEEE Std 829-2008 and IEEE Std 1012-2016.

Verification answers the question: was each component built correctly
according to its specification? Validation answers the question: does the
full system produce results that are scientifically meaningful and consistent
with the research goals?

Each test case is assigned a unique identifier (TC-XX), linked to the
corresponding functional requirement from the System Requirements and Design
Specifications, and records the expected outcome, the actual outcome, and
the result.

% ─────────────────────────────────────────────────────────────────────────────
\section{Scope}

The following components are covered by this report:

\begin{itemize}[leftmargin=2em]
    \item Data ingestion and integrity checks (FR-1)
    \item QUBO matrix construction (FR-2)
    \item Binary search convergence and feasibility (FR-3, FR-4)
    \item k-NN localization evaluator (FR-6)
    \item Time-to-Solution calculation (FR-7)
    \item Greedy baseline correctness (FR-5)
    \item Multi-run statistical experiment (FR-8)
    \item Output file persistence (FR-9)
    \item Figure generation (FR-10)
\end{itemize}

\subsection{TC-02: QUBO Matrix Construction}

\begin{table}[h!]
\renewcommand{\arraystretch}{1.3}
\begin{tabular}{@{}lp{10cm}@{}}
\toprule
\textbf{Requirement} & FR-2 \\
\textbf{Objective} & Confirm that the QUBO matrix $Q$ is built correctly
    for a known value of $\alpha$. \\
\textbf{Method} & For $\alpha = 1.0$, all off-diagonal terms should be
    zero and diagonal terms should equal $-I_p$. For $\alpha = 0.0$,
    diagonal terms should be zero and off-diagonal terms should equal
    $2 R_{pq}$. Inspect the \texttt{build\_qubo} function output
    manually for both boundary cases. \\
\textbf{Expected} & At $\alpha = 1.0$: $Q_{pp} = -I_p$, no off-diagonal
    entries. At $\alpha = 0.0$: $Q_{pp} = 0$,
    $Q_{pq} = 2 R_{pq}$ for $p < q$. \\
\textbf{Actual} & Code inspection of \texttt{build\_qubo} confirms
    the formula matches the specification. The coefficient
    \texttt{coeff\_scale = 2.0 * (1.0 - alpha)} correctly evaluates to 0
    when $\alpha = 1$ and to 2 when $\alpha = 0$, suppressing or enabling
    off-diagonal entries accordingly. \\
\textbf{Result} & \pass \\
\bottomrule
\end{tabular}
\end{table}

\textbf{Actual} & The binary search log (\texttt{binary\_search\_log.csv})
    records the iteration count for each solver. Inspection confirms
    termination within the expected number of iterations. \\
\textbf{Result} & \pass \\
\bottomrule
